SECTION 1

Organisation Profile & Brand Identity

Django Girls Sierra Leone

Non-Profit Technology Education Initiative & Community

1. Background: Founded as a localized chapter of the global volunteer-run movement, Django Girls Sierra Leone empowers young women across Freetown, Bo, and Kenema with practical, entry-level web programming skills using Python and the Django web framework. Since 2020, the initiative has introduced over 350 women to technology through intensive coding workshops.

2. Mission & Vision:
• Mission: To close the gender gap in Sierra Leone's digital economy by delivering free, high-caliber programming workshops, fostering supportive mentorship networks, and preparing women for software development careers.
• Vision: A vibrant, gender-balanced West African technology ecosystem where women build, lead, and innovate impactful digital solutions.

3. Services & Key Offerings:
• Free weekend coding bootcamps for absolute beginners.
• Curriculum-based self-paced learning tracks (Python, Web Foundations, Django MVC, Git/GitHub).
• 1-on-1 personalized mentorship matching with experienced software engineers.
• Collaborative peer-to-peer discussion forum and community knowledge base.

4. Target Users: Female university students (ICT, Computer Science, Engineering), early-career career switchers, high school graduates, beginner hobbyists, and professional volunteer software mentors.

SECTION 2

Problem Statement & Empirical Research

1. Existing Problem:
In Assignment 1, a basic authentication module and static dashboard were implemented. However, the organization previously relied on fragmented third-party channels (WhatsApp group chats, paper signup sheets, unorganized Google Drive folders) to handle event logistics, workshop RSVPs, and learning resources. This resulted in:
• High drop-out rates due to lack of structured progress tracking.
• Uncoordinated workshop RSVPs leading to laboratory over-capacity at university ICT labs.
• Junior learners feeling isolated between workshop bootcamps without dedicated mentor support.

2. User Needs Analysis:
• Learners/Members: Require a centralized portal to register for workshops, track personal curriculum completion, download lesson cheat sheets, and ask questions when stuck on coding errors.
• Mentors: Need a clean directory to review mentee applications, schedule 1-on-1 support, and review code.
• Administrators: Demand real-time attendance analytics, capacity controls, user role management, and exportable reports for funding accountability.

3. Proposed Web Solution:
Transformation of the Assignment 1 authentication prototype into an enterprise-grade Full Organisation / Community Management Platform built in procedural & object-oriented PHP with MySQL, featuring session security, role-based access control (RBAC), event registration tracking, categorized curriculum progression, and admin KPI reporting.

4. Target Audience Demographics:
• Primary: 18–35 year old aspiring female developers in Sierra Leone.
• Secondary: Volunteer senior developers, corporate tech sponsors, and academic facilitators.

MODULES 1 – 3

Auth & Profile Engine

1. Homepage (index.php): Features responsive brand navigation, hero artwork banner, three core community pillars, live calendar sneak peeks, and direct CTA buttons for signing up.

2. User Registration (register.php): Rigorous client and server-side validation. Allows selecting role (Member or Mentor), enters skills, enforces 8-character password hashing using PHP password_hash(), checks duplicate emails, and auto-enrolls new members in default training tracks.

3. Login & Session Security (login.php): Authenticates against bcrypt hashes with password_verify(), calls session_regenerate_id(true) against fixation, supports "Remember Me", and features role-based redirection.

4. Member Profile & Avatar Upload (profile.php): Displays member credentials, editable bio, skills, and GitHub/LinkedIn URLs. Features multipart file upload checking MIME types (JPEG, PNG, WEBP) and 3MB size limit with secure storage in assets/uploads/avatars/.

MODULES 4 – 6

Dashboard & Learning Engine

5. Interactive Dashboard (dashboard.php):
• Personalized welcome card greeting user by name with role badge.
• 4 KPI analytics widgets (Overall Progress %, Registered Workshops, Forum Posts, Mentorship Status).
• Dynamic training progress bars displaying percentage completion with one-click module completion updates.
• Registered workshops list with date, venue, and lead speaker details.

6. Events & Workshop Hub (events.php):
• Category filter chips (Workshop, Bootcamp, Webinar, Networking).
• Seat capacity counter indicating remaining seats in real time.
• 1-click RSVP registration and cancellation engine preventing duplicate signups.

7. Learning Library (resources.php):
• Keyword search bar and topic filter chips.
• Categorized cards for Python, Django, SQL, and Git resources with direct links to official guides and documentation.

MODULES 7 – 9

Community & Administration

8. Discussion Forum (community.php & thread.php):
• Channel filtering across general discussion, help desks, and career channels.
• Thread creation with view counter increment and reply counter.
• Nested discussion replies showing author avatar, role badge, and timestamps.

9. Mentorship Connections (mentorship.php):
• Public mentor directory showcasing verified senior engineers with skill tags and biographies.
• Interactive modal to submit personalized mentorship applications.
• Dedicated mentor action center to Accept or Decline incoming requests.

10. Administrative Panel (admin/):
• Role-based gatekeeper restricting access to verified administrators.
• User management table with role promotion and account suspension.
• Workshop scheduler and real-time attendee roster inspection.
• Exportable CSV analytics reports on participation and curriculum progress.

ARCHITECTURE

3-Tier System Architecture & Navigation

The platform follows a secure 3-Tier Web Architecture model separating presentation, business logic, and relational persistence:

1. Presentation Tier (Client Browser): Semantic HTML5, CSS3 Custom Properties (Tahoma font, responsive design), Vanilla JavaScript for modal controls and mobile menu toggles.
2. Application / Logic Tier (PHP 8 / Apache Web Server): Secure session manager, PDO abstraction layer, password hashing engine, form validation, Role-Based Access Control (RBAC).
3. Data Storage Tier (MySQL Database): 10 relational tables enforcing referential integrity with foreign keys and cascading deletes.

Site Navigation Structure:

[Public Level] → index.php | events.php | resources.php | login.php | register.php
  ↓ (Authenticated Session)
[Member Level] → dashboard.php | profile.php | community.php | thread.php | mentorship.php | logout.php
  ↓ (Admin Role Required)
[Admin Level] → admin/index.php | admin/users.php | admin/events.php | admin/resources.php | admin/reports.php

Core Workflow: Workshop Registration & Tracking

Visitor registers → logs into dashboard → browses events.php → checks capacity → clicks "Register" → system writes unique compound key into event_registrations → workshop appears in personalized dashboard schedule → admin views attendee roster in admin/events.php.

DATA MODEL

Relational Database Schema & ERD

The relational database djangogirls_db consists of 10 interconnected tables designed to Third Normal Form (3NF):

Table Name Primary Key Foreign Keys & Key Columns Description
users id (INT) email (UNIQUE), role (ENUM), password_hash Stores member, mentor, and administrator accounts.
events id (INT) created_by → users(id) Schedules workshops, bootcamps, dates, and capacities.
event_registrations id (INT) event_id → events, user_id → users (UNIQUE) Tracks member workshop RSVPs and attendance status.
learning_tracks id (INT) title, total_modules Curriculum definitions (Python, Web, Django, Git).
member_progress id (INT) user_id → users, track_id → learning_tracks Maintains individual student module completion progress.
resources id (INT) created_by → users(id), category, type Tutorials, code cheat sheets, and video links.
forum_categories id (INT) slug (UNIQUE), name Discussion boards for help desk, general, careers.
forum_threads id (INT) category_id → forum_categories, user_id → users User-submitted discussion topics and view counters.
forum_replies id (INT) thread_id → forum_threads, user_id → users Community answers and peer-to-peer discussions.
mentorship_requests id (INT) mentee_id → users, mentor_id → users Connects beginner mentees with senior mentors.
